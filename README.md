# Week 1 – Data Analyst Internship

## Project Overview
This project was completed as part of my Week 1 Data Analyst Internship. It focuses on Excel fundamentals, data cleaning, Pivot Tables, descriptive statistics, and sales data visualization.

## Tools Used
- Microsoft Excel 2019
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Conditional Formatting
- Slicers

## Tasks Completed

1. Removed duplicate records and checked missing values.
2. Created a Region-wise Sales Pivot Table.
3. Calculated Mean, Median, and Mode using Excel formulas.
4. Applied Conditional Formatting to highlight the top 10 sales.
5. Created a bar chart showing Category-wise Revenue.
6. Created an interactive Sales Performance Dashboard.

## Dashboard Features
- Total Revenue
- Total Order Lines
- Sales by Category
- Yearly Sales Trends
- Revenue by Sub-Category
- Sales by Region
- Region and Category slicers

## Data Cleaning Notes
- Duplicate records were checked.
- Missing Postal Code values were identified.
- Unknown Postal Code values were left blank rather than filled with incorrect information.

## Dataset Limitation
The provided Orders dataset does not contain a Department column. Therefore, Department-wise Revenue could not be created. Revenue by Sub-Category was used as an alternative analysis.

## Learning Outcomes
- Understanding Excel data cleaning.
- Working with Pivot Tables and Pivot Charts.
- Applying descriptive statistical formulas.
- Creating interactive dashboards.
- Analyzing and presenting sales data.
